# Tactic: forward_intercept

- Trigger: a high-value Red target enters the Blue responsibility area.
- Evidence: a Blue intercept node sits upstream on the Red route; the weapon is ready.
- Decision: shoot first with a medium-range missile, keeping at least one sensor tracking.
- Parameters: intercept range, sensor timing, rules of engagement.
- Check: Blue intercepts before Red reaches the asset, and survives.
