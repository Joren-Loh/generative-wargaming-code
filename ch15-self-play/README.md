# Chapter 15 — One round of self-play

Pairing, seeds, sixty games, Elo. The recorded tournament is the one quoted in the book, so the table can be recomputed from the raw results.

**Entry point:** `tournament.py, elo.py`

**Run it:**

```
python tournament.py --rounds 3, then python elo.py
```

**Notes:** Needs a local engine; 60 games take about four minutes on one core.

**Files in this directory**

- `tournament.py`
- `elo.py`
- `arena.py`
- `scenario_template.txt`
- `runs/tournament.json`
