# Chapter 10 — Four tools, not forty

What each tool returns on real input: the type catalogue, a run, an analysis of the event file, and a background launch. The responses are recorded, not invented.

**Entry point:** `tools/types.py, tools/run.py, tools/analyze.py, tools/launch.py`

**Run it:**

```
python server.py, then call each tool from the demo client
```

**Notes:** Needs a local engine for run and analyze.
