# Chapter 19 — The conversational wargame

Two panels, four states, and one rule: the system never silently rewrites what the human asked for. The transcript is a real session.

**Entry point:** `wargame.py`

**Run it:**

```
python wargame.py --transcript transcript.txt
```

**Notes:** Needs a local engine.
