# Chapter 21 — Narrative bound to events

Every sentence in the report traces back to an event line, and the tracer complains when one does not. Prose that cannot cite its event is rejected.

**Entry point:** `narrate.py`

**Run it:**

```
python narrate.py --evt output/scenario.evt
```

**Notes:** Pure standard library.

**Files in this directory**

- `narrate.py`
- `output/report.md`
- `transcript.txt`
