# Chapter 1 — What the engine actually models

One platform, one mover, one processor and the six lines of output they produce. This is the smallest scenario that still means something.

**Entry point:** `scenario.txt, run.bat`

**Run it:**

```
mission.exe scenario.txt (or run.bat on Windows)
```

**Notes:** Runs on a local AFSIM 2.9 installation.

**Files in this directory**

- `README.md`
- `console.txt`
- `mission.log`
- `output/scenario.evt`
- `output/scenario.log`
- `run.bat`
- `scenario.txt`
